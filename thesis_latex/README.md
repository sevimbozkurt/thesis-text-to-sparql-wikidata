# Thesis LaTeX sources

```
latexmk -pdf thesis.tex          # or: pdflatex, biber, pdflatex twice
```

| Path | Contents |
|---|---|
| `thesis.tex` | Preamble and chapter order |
| `references.bib` | Bibliography (biblatex, biber) |
| `chapters/` | One file per chapter, plus title page, front matter and declaration |
| `tables/` | Tables generated by `../make_tables.py` and `../make_appendix.py` |
| `figures/` | Figures generated by `../make_figures.py`; sources in `../results_tables/figure_manifest.csv` |
